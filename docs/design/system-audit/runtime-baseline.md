# Rendered Baseline

Date: 2026-09-16. Local app: `http://127.0.0.1:3017`. Signed-in existing session. Browser screenshots and accessibility trees were inspected in the current task; captures are visible in its tool history. This is a representative baseline, not a complete visual audit of every route and state.

No assignment was edited, no timer or AI request was started, no file was uploaded, no account setting was saved, and no sharing/connection action was submitted. Navigation and read-only UI selection only. Existing route mounts can still run their normal application effects; this is not a network-level assertion of zero background traffic.

Default desktop browser viewport measured at 1134 x 822 CSS pixels; screenshot output can be scaled and exclude the scrollbar. Dynamic record IDs came from visible links, not invented fixtures or hidden application state.

## Evidence Still Required

- All active routes and settings/query variants at desktop and phone sizes, including real empty and populated data where safely available.
- Auth/signup/onboarding and public token/private share states in isolated fixtures. Do not sign out the user's session or consume a real link to manufacture a test.
- Capture conversion, submission receipt, quiz results, connection failures, permissions, record mutations, and unsaved editor behavior in controlled test data.
- Browser/device performance, assistive technology, actual phone keyboard behavior, and user approval. Neither source coverage nor desktop screenshots establish these.

New preview verification is recorded separately so its results are not attributed to the unchanged live screens.
