# Synthetic PDF export verification

The local production build was tested with the retained synthetic campus account after validating its ownership tag. The Review and Hand-in screens displayed the synthetic work, PDF action and explicit school hand-in directions. The Hand-in **Download PDF** button was exercised with narrowly authorized synthetic fixture mutation. The resulting PDF was downloaded, parsed, text-extracted and rasterized; visual inspection found a readable title, problem and answer with margins and no apparent clipping. This verifies the one-page synthetic example, not every possible long document, image or subject.

The prepared delivery file was verified as bound to the synthetic owner and assignment; the assignment remained in its existing `exporting` state and was not submitted. `synthetic-delivery-cleanup.json` contains the file and storage-object metadata for removal by the fixture owner; it contains no signed URL. The authenticated, read-only canonical PDF endpoint independently returned HTTP 200 and `private, no-store`, and its PDF parsed successfully. No school provider was contacted.

The first public-share attempt was unavailable because the fixture initially supplied a digest while the database trigger derives that digest from its separate token column. The synthetic share record was repaired using its existing private fixture token. The targeted follow-up verified an expired link reports unavailable, then the valid recipient view at desktop and 390 px: the due count matched the two synthetic assignments, and synthetic private note/work text was absent. No new share, real recipient, or email was created. See `share-followup-results.json`; `share-followup-before-server.json` retains the initial mismatch diagnosis and the interrupted server attempt.

The first printed shared summary was readable but reached the page edge and included the Print report button. The scoped print CSS was corrected. On the rebuilt app, `print-followup-results.json` verifies actual print media, a hidden action, a readable one-page PDF without action text, and text bounds inside a 36-point safety margin. `shared-summary-page-1-before-print-fix.png` and `shared-summary-page-1-fixed.png` retain the before and after evidence. Expired/valid recipient evidence predates the final print-only CSS rebuild; the final print test used the same valid synthetic share.

The exact synthetic delivery object and database binding created by this test were deleted after checking their bucket, owner and assignment; `synthetic-delivery-cleanup.json` records the verified outcome without retaining a signed URL or object key. The synthetic fixture itself remains for the primary QA cleanup.
