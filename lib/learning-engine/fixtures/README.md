# Recovered learning regression contract

`recovered-primary-contract.json` records deterministic behavior from Git commit
`f5aca1d1078c64915d58a278422688a84e091507`. It replaces tests that depended on
untracked release artifacts unavailable in a clean checkout.

The contract contains source SHA-256 values, the parser implementation digest,
prompt digests for the source-length boundaries used by the original test,
parser fallback examples, and exact serialized Responses request digests for
each quality level, JSON setting, and text/image/file input variant. Inputs are
synthetic. It contains no credentials, learner content, or provider responses.

Source hashes normalize CRLF to LF so Git checkout settings cannot change the
contract. The parser body hash excludes only its initial `Buffer` import. Prompt
and request hashes cover the actual strings without whitespace normalization.

The baseline was generated by reading the listed sources directly from that
immutable Git commit, transpiling them with TypeScript, and evaluating their pure
exports without network access. The tests compare the working implementation to
these fixed results. Updating them requires reviewing the intended prompt,
serialization, or parser change against the recorded source commit. Do not
regenerate them automatically from the working tree to make a test pass.

This is regression evidence. It does not replace the missing historical review
receipts or establish independent review, deployment approval, model quality, or
production eligibility. Runtime authorization and provider-boundary tests remain
separate requirements.
